# 0.15.0-alpha

UnifiedActivity extends the paper dashboard without deleting prior activities or local data. Shared legacy shape/background/text colours map to paper/ink; Android's light theme also covers default dialogs, spinners and inputs. Media, artwork, game boards and provider-owned webpages retain content colours. Seasonal accent choices remain. Responsive cards stack on narrow available widths and toolbars scroll rather than squeeze. Fullscreen actions are suppressed, immersive requests become normal-window requests, and window flags are cleared on page/layout/focus/configuration changes. System bars remain subject to OS/firmware policy.

Watch & Explore is available from Home, Explore and Cameras: Alveus/Winnie, seasonal Fish Doorbell, Snapshot Safari classification, Explore nature cams, seasonal SVT Moose Migration, six Monterey Bay Aquarium camera pages and its directory, Zoolife, historic Amazing FishCam, recorded ESO fulldome shows and Northern Lights. Provider pages, not scraped streams or fake native interactions. State notes checked November 17, 2026 are explicitly dated: Fish Doorbell seasonal closure, Snapshot Safari no active projects, FishCam tank relocation/outdoor view. They are not a background status monitor. Aquarium live hours/off-hours recordings remain provider-labelled.

The opt-in HTTPS viewer uses JavaScript/DOM storage, no app bridge, no file/content access, no geolocation bridge or credential injection, media user gestures, normal certificate validation and API21+ mixed-content blocking. Failed main-page loads show Unavailable with Retry/Browser. A loaded page is not a verified video stream; script/player failures can still require the browser. Browser playback is controlled by that browser. Embedded playback stops on backgrounding and must be retried. API17 and API23+ error clients are separated; compatibility is not guaranteed on the old frame.

School notes become a workspace with title/section, Type/Ink/PDF tabs, selected-text bold/italic/underline/heading, plaintext bullet/checklist prefixes, clear selected formatting, bounded session text undo/redo, pen/highlighter and saved/unsaved status. Checklists are editable text, not tappable task widgets. Existing plain notes load unchanged. Newly saved bodies use SKYNOTE/1 plus JSON text/span ranges in the existing body column; ink and PDF references remain separate. Plain body and rich encoding writes share a SQLite transaction. Failed saves retain an in-memory draft and show NOT SAVED; they are not durable crash recovery. School search decodes formatted text. Existing JSON export includes rich bodies; older app versions cannot render this format, and export still has no restore UI. No database schema change.

New drawings use all remaining workspace below visible controls, without the old fixed-height/letterboxed FitStage or fullscreen toggle. Touch mapping uses the entire view, stable active-pointer tracking and move history; taps produce dots. Paint backing size follows viewport aspect ratio with a 1600-pixel maximum dimension. Existing paint is uniformly fitted into new bounds on resize to preserve proportions, not stretched; repeated size changes can resample raster strokes. Colouring outlines are uniformly fitted. Saved PNGs use current backing dimensions. Imported legacy Studio projects retain their original content representation.

Source changes only: no local Android SDK build or device verification was performed here. CI must confirm compilation; then test theme contrast, orientation/keyboard resizing, note round trips/export/save failure/undo, whole-canvas edge drawing, repeated resize/undo, provider errors and playback on the actual frame. No claim of successful builds, streams or all-device compatibility.
