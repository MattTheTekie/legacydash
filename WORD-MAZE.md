# Word-family maze correction

Replaces the accessible Word Trail menu entry with an original corridor maze based on the supplied worksheet's mechanic: follow connected words ending in a target word family, not letter-wheel swiping or a word-search grid. Does not reproduce the copyrighted worksheet image, design or exact maze.

Six-by-six daily deterministic perfect mazes, generated by randomized depth-first search with one route to the exit. Correct-route cells contain family words, branch cells contain other-family distractors. Families: -en, -at, -op and -ip. Tap adjacent words through open corridors; wrong-family moves rejected. Prior-step backtracking, next-step hint, restart, local saved progress and text directional controls are included. Words can repeat. This is a small educational starter vocabulary, not a comprehensive phonics curriculum. -en words include then/when/wren as literal ending matches.

Crossword remains available. Existing five-letter guess progress is preserved. Old Word Trail source remains inherited but is no longer linked from the games menu. Version remains 0.3.0-alpha; take the new Actions artifact after a successful build. Source is not compiled or device-tested here. API 17 configuration from prior update retained.
