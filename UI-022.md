# 0.22.0-alpha / coordinated UI cleanup

RefinedActivity is the launcher, preserving application ID and existing data. It explicitly builds the sidebar in this order: Home, Photos, School, Games, Explore, Uploads, Apps, Settings. Home uses card grids instead of the old horizontal shortcut strip. School, notebook pages, Albums/Photos and Uploads receive card-based hubs with their existing actions. Daily Notes receives a paper-card editor. Existing Immich album selection/cover browsing and gallery playback remain inherited, not replaced with mock albums. This is still based on the legacy inheritance stack, not a complete architecture rewrite.

Home weather uses matching-location cached conditions and an inline temperature/symbol row with no space before degrees and a 10dp symbol gap. WeatherMotion animates sun rays, clouds, precipitation, fog/storm symbols using the supplied weather code; unknown conditions show a question mark instead of fabricated weather. It is decorative visualization of cached model data, not live observations. Retrieved/stale labels remain. The large native forecast header's static icon and 22dp gap are replaced with a 64dp animated symbol and 10dp gap; smaller daily icons remain static. Weather motion has an independent Settings toggle. Animation callbacks stop on detach/background.

The opportunistic CornerPet overlay is removed from normal content. Standard shell pages reserve a 56dp footer dock with the animated companion aligned right, so it no longer disappears merely because the page is full. The dock respects pet.dock and hides in editors, fullscreen, media galleries and provider workspaces; it does not overlay controls or artwork. On small screens this reserves vertical space rather than pretending free space always exists. Existing pet state and care behavior remain.

Typing-focused EditTexts prevent automatic focus/fullscreen hiding, avoiding the first-tap reveal handler stealing routine cursor-placement taps while editing. Modern IME insets and a display-frame fallback supplement focus detection. School note text keeps native touch/selection handling and avoids select-all-on-focus. Ink still intentionally captures drawing; choose Type to place the text cursor. Existing transparent ink, autosave and coordinate-not-semantic anchoring limitations remain.

Weather TV opens a dedicated landscape immersive WeatherKioskActivity with a full-size WebView, wide viewport and overview scaling, no sidebar/pet/seasonal overlay. Tap reveals a transient Back/Reload/Browser overlay; the initial reveal gesture is consumed. Location and music remain provider controlled, media requires user gestures, errors are explicit, and embedding stops on backgrounding. This is WeatherStar 4000+, not an official Weatherscan broadcast, and wide viewport does not guarantee the third-party site's own layout or compatibility on an API17 WebView. HTTPS/certificate/file-access protections remain.

Add to bookshelf uses a single picker for PDF, EPUB and UTF-8 text. BookImport copies within quotas, detects PDF header or verified EPUB ZIP metadata, otherwise validates bounded UTF-8 text and rejects binary data. The existing PDF/EPUB parsers validate actual content and produce covers/metadata. File extension and MIME hints do not select a separate user workflow. Import remains limited to 100 books, about 250MB total, 50MiB per file and 8MB TXT. Files use generated local IDs; failed imports clean up their target/cover. Existing bookshelf data, school links and reader paths remain. Upload QR's existing import implementation is not replaced. Cross-channel concurrent bookshelf-index updates remain a legacy limitation.

No Android build or device test was run.
