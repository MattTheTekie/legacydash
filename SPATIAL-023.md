# 0.23.0-alpha / kiosk parameters, upper photos and spatial notebooks

Weather TV now loads https://weatherstar.netbymatt.com/?viewMode=wide&kiosk=true in both its embedded view and browser fallback. This activates provider parameters in addition to Android landscape/fullscreen. Setup opens the same provider with kiosk=false so its own location/music/settings can be changed; Reload kiosk restores the kiosk URL. No location, provider data or audio playback is fabricated or guaranteed.

Home moves its real photo panel out of the bottom of the navigation cards. On wide screens it sits alongside a vertically stacked Today/School-agenda column near the top; on smaller screens it appears immediately after the weather summary, before day information and navigation cards. No duplicated panel or mock images are added.

School notes use a shared 1000-unit-wide vector document with independently positioned editable text boxes and freehand strokes. Text mode taps blank paper to create a box at that point; existing boxes retain native caret placement and text selection. Pen/Highlight draw over the same document. A stylus can draw while Text mode remains selected for finger typing. Finger-only use requires choosing Text versus Pen/Highlight; a single finger gesture is not ambiguously treated as both. Move drags a text box; Scroll allows panning; Zoom adjusts the view rather than resampling stored coordinates. Selected text supports bold/italic/underline/heading and editable bullet/checklist prefixes. More adjusts box width/font or deletes a selected box. Undo/redo snapshots are session-only and bounded.

Text mode does not auto-hide the shell, so the first placement tap is not consumed by the fullscreen reveal handler. Pen/Scroll modes retain idle fullscreen behavior. Metadata hides while a document text box has focus to leave more keyboard space. Existing PDF references, note title/section, autosave, save status, search and JSON export are retained. Original PDF files and PDF annotation behavior are unchanged.

Saved spatial bodies use SKYSPATIAL/1 plus JSON blocks/strokes/plain search text. Existing plain/rich text loads as an initial editable block; legacy ink remains stored separately and is rendered on a legacy document area. On first edited save, original body/ink are also embedded in a legacy snapshot. Opening alone does not rewrite the saved note. This preserves source data, but cannot guarantee pixel-perfect positioning of older handwriting whose original canvas dimensions were not stored. Older app versions cannot render the spatial body format. Export includes it as the existing body string; no restore UI is added.

Limits: 80 text boxes, 50,000 total typed characters, 600 new strokes, 12,000 new ink points, 200,000 logical units maximum document height and bounded session history. Legacy ink remains subject to its existing limits. A save failure retains a session draft where serialization succeeded and reports NOT SAVED; memory-only work is not crash recovery.

No Android build or device test was run. CI and device verification must cover Java/API compatibility, actual provider URL behavior, initial location setup, Home placement at narrow/wide widths, text-box insertion/caret/IME, stylus/finger routing, move/zoom/scroll, formatting/history, legacy note preservation, spatial save/reopen/search/export, PDF links, fullscreen behavior and casting inheritance.
