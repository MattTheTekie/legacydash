# 0.37.0-alpha / stable fullscreen and native date/time inputs

Removes the remaining explicit normal-page resets: FrameActivity.page no longer clears FLAG_FULLSCREEN, and GalleryActivity.page no longer zeros system UI flags on every menu transition. The shared controller keeps fullscreen when an EditText receives focus, applies normal-window requests synchronously/idempotently and retains stable/fullscreen layout flags. API19+ includes immersive-sticky/layout-hide-navigation. No viewport keyboard-size polling returns. Pet attachment remains separate; no hiding of the pet is used to mask a resize.

Native page keyboard mode is ADJUST_PAN. Real keyboard opening can still pan content, and system gestures/dialogs/vendor policies can expose bars; this is not lock-task enforcement. Text editing and inset/cutout behavior require device testing, particularly old Android. Gallery networking/session code is otherwise unchanged.

NativePickers binds date/time EditTexts identified by explicit YYYY-MM-DD, MM-DD, HH:mm hints or Android datetime input types. Discovered app fields include assignment due dates, daily-note dates and month/day birthdays. Values retain yyyy-MM-dd, MM-dd or HH:mm storage, with sequential native pickers for datetime inputs. The system time picker follows the device 12/24-hour preference. Optional date fields offer Clear; birthday choice uses leap year 2000 and stores no year. Read-only picker fields suppress the typing keyboard and work by tap or Enter/Space/D-pad activation. Plain note bodies, URLs, numeric durations and unrelated inputs are not converted merely because their contents contain dates.

The calendar month title and selected-date label also open the native DatePickerDialog, with existing autosave failure handling respected before changing the selected date. The custom month grid remains available. Existing light/dark schedule controls already use TimePickerDialog and are retained. Changing a daily-note date still requires its existing Load date action to load that date's content; no automatic discard/save policy is added. This does not set the device clock or add date/time-setting permissions. Unrelated picker fields outside the native dashboard hierarchy are not universally rewritten. Platform picker appearance/ranges follow the installed Android version/theme.

No Android build, device test or fullscreen recording was run. Verify CI; rapid menu navigation; keyboard open/close; default focus; optional-date clearing/cancellation; birthday Feb 29; daily-note date/load/save; assignment dates; calendar jumps and save errors; 12/24-hour inputs; pet positioning; rotation; dialogs/media/kiosk and OS navigation.
